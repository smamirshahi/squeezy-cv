# Contributing

Thanks for looking. Squeezy CV is a personal project that I build in my own time, and **I am not accepting pull requests for now**. This is so I can keep the direction and the saved-data format steady, not because I don't value your interest.

## What helps

- **Bugs and ideas:** open an issue. For a bug, say what you did, what you expected, what happened, and whether you use the browser version or the local server. Please do not paste your real CV or any personal data.
- **Questions:** an issue is fine.
- **Security problems:** do not open a public issue. See [SECURITY.md](SECURITY.md).

I read issues when I can and can't promise a reply or a fix date.

## Want to change it for yourself?

You are welcome to fork it and make it your own; the [licence](LICENSE) (PolyForm Noncommercial 1.0.0) allows that for any non-commercial purpose. The README explains how to run it, and `CLAUDE.md` and `docs/` describe how the code is laid out.

## If this changes later

If I start accepting pull requests, this file will say so and explain how (an issue first, small changes, the checks to run before you push).
